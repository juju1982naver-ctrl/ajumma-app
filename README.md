# 수빈서아맘 나들이

양주를 중심으로 의정부·동두천·연천·포천의 행사 소식을 모아 보는 개인용 안드로이드 앱입니다.

- 탭 3개: 공연·전시 / 체험·교육 / 축제·장터
- 지역 고르기: 전체·양주·의정부·동두천·연천·포천
- 오늘 이후 행사만 날짜순으로 보여줍니다.
- 행사를 누르면 시간·장소·요금·설명, 원문 보기, 지도에서 보기가 나옵니다.

## 앱 받기

[Releases의 latest](../../releases/tag/latest)에서 `ajumma5.apk`를 휴대폰으로 받아 설치합니다.
처음 설치할 때 "출처를 알 수 없는 앱 설치 허용"을 한 번 켜야 합니다.

## 행사 목록 고치기

앱은 켤 때마다 `data/events.json` 파일 하나만 읽습니다(서버 없음).
이 파일을 고쳐서 `main`에 올리면 앱을 다시 설치하지 않아도 목록이 바뀝니다.
인터넷이 안 되면 마지막으로 받은 목록을 보여줍니다.

각 행사 항목:

| 이름 | 뜻 | 예 |
|---|---|---|
| `category` | `공연·전시`, `체험·교육`, `축제·장터` 중 하나 | `축제·장터` |
| `region` | `양주`, `의정부`, `동두천`, `연천`, `포천` 중 하나 | `양주` |
| `title` | 행사 이름 | |
| `startDate`, `endDate` | 시작일·끝일 (`YYYY-MM-DD`, 하루짜리면 같게) | `2026-10-31` |
| `time`, `place`, `fee`, `description` | 시간·장소·요금·설명 (없으면 빈칸) | |
| `url` | 원문 주소 | |

맨 위 `updated`는 목록을 만든 날짜입니다.

## APK 빌드

`main`에 코드가 올라가면 GitHub Actions가 APK를 만들어 Releases의 `latest`에 올립니다.
`data/` 폴더만 바뀐 경우에는 다시 빌드하지 않습니다.

빌드할 때마다 서명 키가 새로 만들어지므로, 새 APK로 업데이트할 때 "설치할 수 없음"이 나오면
기존 앱을 지우고 다시 설치하면 됩니다(행사 목록은 인터넷에서 다시 받습니다).
